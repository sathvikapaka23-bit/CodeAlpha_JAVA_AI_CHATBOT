# AI Chatbot

## CodeAlpha Java Programming Internship

### Task 3: AI Chatbot

This project is a simple console-based AI Chatbot developed using Java as part of the CodeAlpha Java Programming Internship.

The chatbot interacts with the user through the command line and provides responses based on keywords and phrases detected in the user's input.

## Features

- Interactive chat with the user
- Greeting recognition
- Java-related responses
- Python-related responses
- Artificial Intelligence information
- Machine Learning information
- College-related responses
- Help command
- Thank-you response
- Exit using `bye` or `exit`
- Basic Natural Language Processing using keyword matching

## Technologies Used

- Java
- Object-Oriented Programming
- String Processing
- Conditional Statements
- Scanner
- Basic NLP Concepts
